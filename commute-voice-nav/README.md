# 통학로 음성 안내 (시연)

중앙대·숭실대 통학로를 시각장애인 위험도 지표 하나(A 횡단 / B 경사 / C 인지 복잡성, 또는 최단)를 골라 그 기준으로 경로를 찾고,
걷는 동안 회전과 위험 지점을 음성(OpenAI TTS로 미리 만든 mp3, 없으면 브라우저 음성)으로 안내한다. 지표는 합치지 않는다.

- `index.html` — 페이지 (Leaflet + OpenStreetMap)
- `nav_engine.js` — 경로 계산·안내 엔진 (브라우저와 Node 시뮬레이션이 같은 코드를 씀)
- `data_*.json` — 학교별 보행망과 지표, `clips.json` — 음성 조각 문장, `audio/` — 음성 파일

프로젝트 시연용이며 실제 보행 보조 기기가 아니다. 위험도 지표 대시보드: `../commute-risk-dashboard/`
